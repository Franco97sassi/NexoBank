# NexoBank

Plataforma bancaria full stack para la gestión de cuentas, movimientos y transferencias.

## Stack

### Backend

- Java 21
- Spring Boot
- Spring Security
- Spring Data JPA
- PostgreSQL
- Flyway

### Frontend

- React
- TypeScript
- Vite
- TanStack Query
- React Hook Form
- Zod
- Ant Design

### Infraestructura

- Docker
- Docker Compose
- GitHub Actions

## Funcionalidades iniciales

- Autenticación
- Clientes
- Cuentas
- Movimientos
- Destinatarios
- Transferencias
- Comprobantes
- Auditoría
